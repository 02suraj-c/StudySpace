# ✨ StudySpace – Student Task Manager

A simple, aesthetic, and responsive web application that helps students organize academic tasks, manage deadlines, and track their productivity.

## 📌 About the Project

StudySpace is a student-focused task management application built to make daily academic planning easier. Students can create tasks, set deadlines, assign priority levels, and monitor their progress through a clean and user-friendly dashboard.

With its soothing lavender theme, pastel accents, and responsive design, StudySpace provides a comfortable experience for managing academic responsibilities.

## 🚀 Features

- **Add Tasks:** Create tasks with titles, descriptions, due dates, and priorities.
- **Edit Tasks:** Update existing task details whenever needed.
- **Delete Tasks:** Remove tasks that are no longer required.
- **Task Completion:** Mark tasks as completed.
- **Filter Tasks:** Filter tasks by completion status and priority.
- **Progress Tracking:** View total, completed, and pending tasks with a progress indicator.
- **Overdue Detection:** Identify tasks whose deadlines have passed.
- **Local Storage:** Save tasks in the browser so they remain available after refreshing the page.
- **Responsive Design:** Use the application on desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

- **HTML5** – Application structure
- **CSS3** – Styling, responsive layouts, and pastel-themed UI
- **JavaScript** – Task management and interactive functionality
- **Local Storage** – Browser-based task persistence
- **Git & GitHub**
